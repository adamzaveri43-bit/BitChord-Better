# BitChord builds

Ready-to-install APK, kept apart from the code (this branch shares no history with it).

**BitChord.apk** — optimised (R8) build for 64-bit phones, from branch
`ccr-44089804-pvgg2r` at commit 7946c13. Installs as "BitChord Dev"
(`com.dev.bitchord.benchmark`), alongside the regular app; signed with a debug key.

To install on the phone: open BitChord.apk on github.com, tap **Download raw file**,
then open the downloaded APK.
